# Agents

This file outlines the behavior, configuration, and tools for LLM Agents interacting with this repository.

## Purpose

Agents should use this repository as a knowledge base to answer questions, build solutions, and provide guidance on Salesforce Data 360 and Data Cloud implementations.

## Guidelines

1. **Read-Only Context**: Agents should primarily use this repository to fetch context.
2. **Up-to-Date Information**: When contributing, agents should ensure they update relevant sections in the wiki.
3. **Citation**: Agents should reference specific files and paths within this repository when providing answers based on its content.
