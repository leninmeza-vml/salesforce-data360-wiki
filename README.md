# Salesforce Data 360 LLM Wiki

Welcome to the Salesforce Data 360 LLM Wiki. This repository contains the centralized knowledge base, documentation, and agent configurations for Salesforce Data 360.

## Overview

This project stores critical documentation regarding Salesforce Data 360, Data Cloud, platform encryption, integrations, certifications, and more. It is intended to be used as a source of truth for both developers and LLM agents working with the platform.

## LLM Wiki Navigation

As an LLM Wiki, this repository uses specific files to catalog its knowledge and history:
- [Wiki Index](index.md): A comprehensive, categorized catalog of all documents in the repository. Start here to navigate the knowledge base.
- [Wiki Log](log.md): A chronological, append-only log of updates, ingests, and queries.
- [Agents Config](AGENTS.md): Configuration, rules, and guidance for LLM agents operating within this repository.

## Contents

The wiki includes directories covering various aspects such as:
- Data Cloud Certifications
- Platform Governance and Encryption
- Integration and Connectors
- Analytics and Predictions
- Custom AI and Data Solutions
